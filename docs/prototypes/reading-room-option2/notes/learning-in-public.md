# Learning in public

Learning & making · Sample note

Keep the question, the experiment, and the thing that changed your mind.

## Leave a trail

A useful note can start with a question instead of a conclusion. Keeping the unfinished version makes it possible to return later and see how my thinking moved.

## Keep it small

One observation, one example, one next question. A link to the original source keeps the trail intact, while the note captures what I want to explore myself.

> A small, unfinished note is still a place to begin.
